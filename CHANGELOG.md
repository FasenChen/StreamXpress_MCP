# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - Unreleased

### Added

- Added `pause` and `resume` MCP tools. Pausing preserves the current file position, and resuming does not reload the settings XML or stream.
- Added a `health` summary to `get_status`, including conservative `FILE_NOT_READABLE` and `UNDERFLOW_ERRORS` warnings.
- Added the `clear_errors` MCP tool for resetting the StreamXpress playout error counter.
- Documented the static MCP tool descriptions generated by FastMCP.
- Added project versioning and release conventions.

### Changed

- `play()` now stops an active `PLAY` or `PAUSE` session before loading a new preset and stream.
- `get_status()` now returns the remaining official `SpRcPlayoutInfo` fields: file offsets, played bytes, and loop begin/end times.
- Updated the README tool table and interaction examples for the 9-tool surface.

## [0.1.0] - 2026-08-31

### Added

- Initial local preset-player MCP surface: `launch`, `connect`, `play`, `stop`, `get_status`, and `disconnect`.
- StreamXpress SOAP client wrapper, Windows launcher, configuration lookup, and vendored SpRcApi WSDL client.
- pytest coverage for client, server tools, configuration, launcher, and WSDL discovery.
